## 2. Dominant search intent per cluster

### Cluster A — Tagesgeschäft / Operational use cases
Queries: KI im Tagesgeschäft Großhandel, KI Auftragserfassung Großhandel, KI Bestellungen Großhandel, KI Disposition, KI Tourenplanung, KI Bestandsmanagement, MHD Software

Intent: **use-case research** — the searcher already knows what KI is and wants to understand whether a concrete task in their daily operation (taking orders, routing drivers, tracking MHD) can be improved. They are looking for workflow-level answers, not KI theory.

### Cluster B — Discovery / shortlist
Queries: KI im Großhandel, KI für Großhändler, KI Warenwirtschaft Großhandel, KI Lebensmittelgroßhandel

Intent: **informational/commercial** — Inhaber or Betriebsleiter doing early research. "What can KI actually do for a company like mine? Do I need to replace my WaWi?"

### Cluster C — Digitalisierung / Automatisierung
Queries: Digitalisierung Lebensmittelgroßhandel, Automatisierung Großhandel Warenwirtschaft

Intent: **research / vendor discovery** — broader exploration before a buying process starts. Often triggers ERP comparison results.

## 6. Recommended page angle for ki-grosshandel/index.html

**Angle:** Practical guide from a vertical software company — not a blog post, not a generic AI article.

Answer: "What can AI concretely do for a German wholesaler today, working with the WaWi and processes already in place?"

Structure follows the Tagesgeschäft workflow order: orders in → routing → delivery / returns → invoicing → customer signals → stock/MHD → control model → who fits → how to start.

This directly mirrors the homepage narrative but expands each step into a searchable answer page that earns the informational query while converting commercial visitors.
